NLAMS Prototpe 
Project title: National Land Acquisition & Management System
(NLAMS)
Department label shown in the interface: Ministry of Rural
Development | Department of Land Resources (DoLR)
Overview
NLAMS is a dashboard prototype for monitoring land acquisition
associated with infrastructure projects. The interface brings
compensation summaries, land-parcel status, project progress, and
related management areas into one place.

This README is based on the supplied prototype screenshot. It describes
the visible interface and does not assume backend services, database
integrations, or features that are not demonstrated in the screenshot.
Dashboard
The Overview page contains four summary cards:

  Dashboard metric     Meaning shown in the interface
  Total Compensation   Acquisition value allocated
Disbursed (Paid)     Compensation paid and percentage completed
Disputed Amount      Amount locked in arbitration
Pending Release      Amount awaiting validation

The screenshot currently displays ₹0.00 for all four amounts and
0% completed for disbursement.

Two reporting panels are also displayed:
- Land Parcel Status Overview --- visual summary of land-parcel
  acquisition status.
- Project Progress (Acres Acquired vs Target) --- comparison of
  acquired acreage against the target.
The dashboard also includes an Active Infrastructure Projects
section and a Create Project button.
Main Navigation
The prototype header provides these sections:
1. Overview --- dashboard summary and project monitoring.
2. Projects & Parcels --- navigation area for infrastructure
   projects and their land parcels.
3. RFCTLARR Calculator --- a calculator area labelled for RFCTLARR.
4. Disputes Portal --- an area for handling or viewing
   land-acquisition disputes.
Visible Workflow Areas
Based on the navigation and dashboard labels, the prototype is organized
around the following workflow areas:
- Reviewing compensation allocation and payment status.
- Monitoring amounts pending release or involved in disputes.
- Viewing land-parcel acquisition status.
- Comparing project acreage acquired with project targets.
- Accessing project and parcel management.
- Accessing the RFCTLARR calculator and disputes portal.
The screenshot shows the navigation and dashboard layout; it does not
show the detailed forms or behavior inside each module.
